# 🎬 IMDb Movie Analysis using SQL

## 📌 Overview
This project performs in-depth analysis on an IMDb movie dataset using **SQL**. It answers business-oriented questions by extracting insights related to movies, ratings, genres, and industry trends.

---

## 🎯 Objective
To analyze movie data and derive meaningful insights using SQL queries involving joins, aggregations, subqueries, and window functions.

---

## 📊 Key Features

- Data exploration and cleaning  
- Complex SQL queries for analysis  
- Use of JOINs, GROUP BY, HAVING  
- Subqueries and window functions  
- Business-driven insights extraction  

---

## 🧠 Problem Statement

Analyze the IMDb dataset to answer questions such as:
- Which genres are most popular?
- Which movies have the highest ratings?
- Which directors or actors perform best?
- Trends in movie production over time
- Revenue and rating patterns
